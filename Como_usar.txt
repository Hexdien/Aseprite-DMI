


--------- Como usar AsepriteDMI

Passo 1 - Utilizar o Re-ordenador dream maker criado por mim

Primeiro você precisa utilizar a ferramenta para reordenar os States do icon.

Para utilizar ela, bastar compilar e rodar pelo dream maker, clicar em Reordenar DMI, escolhe o icon que precisa ser re-ordenado, então escolhe o local de saída do resultado.

No fim você terá um icon com os states ordenados pronto para usar a ferramenta AsepriteDMI




Passo 2 - Utilizar o AsepriteDMI na função importar

Você deve escolhe o tamanho do canvas que o icon foi criado, por exemplo 32x32, 64x64....

em seguida, irá gerar 4 camadas.
Cada camada terá todos os frames em sequencias corretas separados por direção.



--------- Exportação por tags

Na função exportar, você pode ativar "Exportar por tags" para que o script leia
as tags do Aseprite em ordem.

Tags comuns são exportadas como animações de 4 direções:
Sul, Norte, Leste, Oeste para cada frame.

Para marcar uma tag como animação de 1 direção, use no nome:

meditar [1]
meditar [1dir]
meditar dirs=1

Nesses casos, o script usa a layer Sul para todos os frames da tag.

Para animações de 1 direção que usam desenhos vindos de layers diferentes,
informe a ordem dentro da tag:

chute giratorio [1:S,L,N,O]

Esse exemplo exporta 4 frames em sequência usando:
frame 1 da layer Sul,
frame 2 da layer Leste,
frame 3 da layer Norte,
frame 4 da layer Oeste.
